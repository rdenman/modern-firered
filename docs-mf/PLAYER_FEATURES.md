# Modern FireRed — player feature list

What 1.0.0 actually changes versus stock FireRed. Kanto’s story and maps stay vanilla. New Game opens a rules menu; Options (pause menu) is Options+.

## Start of run

- **Gamemode:** Classic or Modern presets, or Custom. Fairy, modern types/stats/movepools, type chart, reusable TMs, Synchronize, Sturdy, Sitrus, survive poison, nature mints.
- **Features:** shiny rate, wild item drops, shiny palettes (when assets exist), regional forms (Alolan/Galarian/Hisuian/Paldean; default Off).
- **Randomizer:** wild / trainer / static / starter, similar BST, map-based, legendaries, types, moves, abilities, evolutions, type chart, items, chaos, themed gym parties. Item randomization uses a Gen 3 pool plus later evo items (no Mega Stones / Life Orb / TM51–100).
- **Nuzlocke:** Off / Easy / Normal / Hardcore, species and shiny clauses, nicknames, faint deletion.
- **Difficulty:** party limit, gym level caps, EXP multiplier, scaled EXP, catch rate, item bans, IV/EV scaling, no Centers, no PC heal, expensive shops.
- **Challenges:** evo limits, monotype, BST equalizer, mirror (± thief).
- Illegal combos warn or block at the menu (Fairy monotype with Fairy Off is forbidden).

## Always on in this hack

- Physical/Special split, Fairy in the data, summary IV/EV.
- Linking Cord / Metal Coat from Celadon 4F (trade evos without a second Game Boy).
- After Celio’s Sapphire: MysticTicket and AuroraTicket (Vermilion sailor → Navel Rock / Birth Island). No Mystery Gift.

## Options+

Autorun (and Surf), Even Faster Joy, skip intro, units, fast battles / intro, anim speed, ball prompt, STAB/effectiveness hints, bag cursor memory, run prompt. Header shows **v1.0.0**. **CREDITS** names RHH pokeemerald-expansion and Modern Emerald.

## Out of scope (on purpose)

New maps/story, followers, music packs, Battle Frontier, Altering Cave tables, Wonder Trade, day/night RTC.
